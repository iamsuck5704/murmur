# Murmur v1.5 加害者篇：鑑識式解謎更新

E1 / E2 / E3 / E4 新增「收錄紀錄 → 章節鑑識板指派證據 → 核對」玩法，E3 原有 v1/v2 不同句子核對保留，E5 事件排序保留。第一、第二周目原有資料不修改。

客觀檔案配對有固定核對答案；人物動機與心理狀態不設唯一標準答案。檔案名稱與資料內容不會在選擇器外洩未解鎖章節資訊。舊版已完成的章節保留過關狀態。

操作：在日記或資料頁底部點 [COLLECT]，返回「目前章節」，選擇 [VERIFY] 的證據並核對；完成目標後按「完成本章」。E3 額外需要在差異比對題確認消失的句子。

安裝：將覆蓋包解壓到 `D:\murmur`，在根目錄執行 `npx cap sync android`，再從 Android Studio 執行現有 app。不可執行 cap add android，勿覆寫 android 資料夾。iOS 同樣需要 `npx cap sync ios` 後重新編譯。

狀態：JS 語法與原始碼檢查；原生 Android / iOS 編譯與實機通關仍待測試。
