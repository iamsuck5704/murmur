# Murmur v1.8.0

- 玩家在入場頁選擇「確認並啟用裝置效果」後，已獲 Android/iOS 授權的相機、定位、通知，以及可用的動作、環境光、螢幕擷取事件偵測，預設開啟對應的遊戲效果開關。
- 麥克風音量分析也隨玩家主動選擇且授權後啟用。
- 只接受條款、不啟用裝置效果的選項仍然保留。
- 系統拒絕的權限不會強制啟用。
- 裝置效果並非立刻開始持續擷取；依原有前景、章節與個別事件條件啟動。原有相機與位置對資料用途的額外確認仍保留。
- 入場頁新增直播／螢幕錄影提醒，不透露任何劇情觸發方式。
- 已有的使用者選擇不會被無條件覆寫，須重新在入場授權流程選擇啟用。

## Windows
覆蓋更新包後執行 `npm run build:native`、`npx cap sync android`、`python scripts/patch_android.py`，再於 Android Studio Rebuild/Run。
