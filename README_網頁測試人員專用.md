# Murmur 網頁版測試人員專用入口

## 現有進度規則
- **第一周目完成**：右上選單會顯示「分支授權碼」，可取得包含第一周目進度的 MRM 轉移碼，及已設定的 App 商店連結。
- **第二周目完成**：同一入口的轉移碼升級為包含第一、第二周目的進度。原版網頁的 App 下載提示仍在此處。
- **第三周目**：正式 App 在第二周目完成後可進入；一般公開網頁仍不包含第三周目。

## 新增測試版（與正式網頁分開）
- 新增 `npm run build:tester`，產出 `dist/tester/`，包含第三周目資源，但不改動 `dist/web/`。
- 測試人員可直接在右上角「調查」的**站內搜尋欄**輸入正確的 `MURMUR-QA-...` 授權碼，不必先完成第一或第二周目。
- 測試授權碼格式：`MURMUR-QA-` + 12–40 位大寫英數字；與原本 `MRM-...` 進度轉移碼完全不同。
- 驗證成功時會將目前裝置的主線進度設為**已完成第二周目**，並立即開啟加害者篇。主線進度寫入本機存檔；測試授權本身只在當次頁面有效，重整後再次開啟第三周目須重新驗證。

## 建置（Windows PowerShell）
```powershell
cd D:\murmur
$env:MURMUR_TESTER_CODE = 'MURMUR-QA-請自行產生至少12位大寫英數亂數'
npm run build:tester
Remove-Item Env:MURMUR_TESTER_CODE
```
請用密碼管理器或 GitHub Actions Secret 管理實際測試碼，不要提交到 GitHub。

**安全限制：** 前端驗證僅是 UI 門檻，不是防止原始碼被下載的安全保護。測試版部署到獨立 Cloudflare Pages 專案／測試網域，並且**必須在 Cloudflare Access 設定指定測試者電子郵件登入**。切勿直接公開 `dist/tester`。`robots.txt` 不構成存取控制。一般公開站仍部署 `dist/web`。

**注意：** 此方案未新增後端一次性授權碼服務；若需要逐人撤銷、有效期限或防轉傳，須改為伺服器端授權驗證。測試碼也不代表商店審核人員可自動通關，應另提供審核操作說明。

## 搜尋欄捷徑操作
1. 進入獨立測試站，點右上角「調查」。
2. 在上方站內搜尋輸入完整 `MURMUR-QA-...`，按「搜尋」或 Enter。
3. 成功後自動標記第二周目完成並進入加害者篇；錯誤碼只顯示失敗，不更動存檔。
4. 公開 `dist/web`、Android/iOS `dist/native` 不啟用這條捷徑。

注意：捷徑會直接改寫測試者本機主線進度，測試前建議使用獨立瀏覽器設定檔。
