# Murmur v1.5.1 | 每份文件開啟動畫

- 日記、備忘錄、訊息、搜尋紀錄、草稿匣、行事曆、舊部落格等，只要進入單筆文件都播放 0.72 秒 CRT 中央展開與一次輕微水平扭曲。
- 每筆文件第一次閱讀時，只要有一般文字而且開啟逐字設定，會以 █ 游標逐字顯示開頭最多 280 個字元；其餘立即顯示，避免很長的日記等待數分鐘。
- 重讀文件只播放 CRT 開啟，不重播逐字文字；在同一份文件收錄證據或其他局部重新 render 時不重播。
- 在「減少動態效果」或關閉驚嚇效果時直接顯示。原有特殊場景（重複文字、湧現）保持獨立演出。
- 不更改故事、證據題、原生權限、進度儲存鍵。

## 更新

將 ZIP 解壓至 D:\murmur，覆蓋同名檔案，然後執行 `npx cap sync android`，返回 Android Studio Run。不要執行 `npx cap add android`。
