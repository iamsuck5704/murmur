# Murmur 加害者篇 CMD v0.6：觸控閱讀與文字演出

更新於 2026-10-10。以 v0.5 交接包原始文本為唯一資料來源，**原稿內容不改寫**，只把演出指示轉換為 UI。

## 本版已完成

- 加害者篇閱讀頁：上一筆／下一筆、返回目錄／返回章節。讀檔按鈕可觸區 ≥ 72 CSS px，目錄列 ≥ 76 CSS px。
- 基於系統預裝的 Courier New / 等寬字型 fallback；完全不載入外部 Google Fonts。**本包沒有字型二進位檔**，中文是否為真正等寬仍取決於裝置字型；正式發佈前仍需合法封裝 Noto Sans TC / IBM Plex Mono。
- 從 v0.5 讀到的舞台指示轉成排版特效：空白頁、只有日期、畫線、重複十四次逐漸縮小、撕頁換頁、頁尾留白、已刪除／空白訊息、4/10 人稱改寫、4/15 逐行出現、檢方扣押提示。
- 台詞裡自然出現的括號與思考註記維持原文，不全域刪除。
- 排序謎題預設順序不再直接正確；只有解出才顯示最終內容。
- 可用記錄以已解鎖章節過濾，預覽入口不會偷跑到尚未解鎖的日記。
- 尊重系統 prefers-reduced-motion；無快速閃爍。

## 尚未完成／注意

- 這是可在手機瀏覽器預覽的 App Web 核心，**不是 Android APK/iOS IPA**。沒有原生感測器、通知、實際手機裝機測試。
- v0.5 的文本全部存於 `www/perpetrator.js` 的 ARCHIVE 中，未修改；但完整 ARG 謎題機制（如存取碼與衝突副本時間驗證）仍有待進一步細化，目前部分是線索檢視式流程。
- 尚有系統保留目錄並非完整劇情。`HELP` 與 `OPEN_Q` 仍待正式謎題全部完成後同步更新。
- 交接包的 5 項已定案設定全部保留；4/10 23:51 前後稱呼規則未更改。性暴力不描寫、自傷不寫方法，不以 A 身分勒索。
- 原主線 `#debug`／`#debug-app` 等開發入口尚未移除，**不得以本版直接上架**。

## 使用與測試

- 直接開啟 `www/preview-standalone.html` 可試玩加害者篇的介面；此為「預覽」入口，正式 App 入口依然須完成第一周目或輸入索引碼。
- 本機 HTML 在部分 Android 瀏覽器的 localStorage 可能不持久，建議之後在本機伺服器或真正原生 WebView 測試存檔。
- `python docs/test_v06.py` 執行 Chromium / Playwright 的互動與斷言測試；已測寬 280/320/390/768 CSS px，仍不能代替實機測試。
