# Murmur 商店頁面草稿（待實際分級與素材審核）

**名稱**：Murmur｜默語檔案

**短介紹**：一段聊天，一份被刪改的備份，以及你尚未看見的真相。

**長介紹**：

你收到一段看似平常的對話。訊息逐漸出現矛盾，時間戳記與舊版文件不再一致。當你試圖拼湊真相，新的紀錄卻可能推翻先前的推論。

Murmur 是以手機為主要操作方式的互動式心理恐怖與數位鑑識敘事遊戲。閱讀聊天紀錄、搜尋檔案、比對版本與重建事件時間線。不同周目會揭露不同視角，玩家需要自行判斷哪些敘述值得相信。

部分裝置互動效果為**選用功能**，需經玩家同意並視手機系統支援。拒絕授權仍可繼續故事。

**內容警示**：本作含心理壓迫、跟蹤／控制、強烈情緒衝突、恐怖畫面及可能令人不適的成人主題。實際商店分級應以最終完整內容填答，不預先宣稱特定年齡級別。

**商店素材待製作**：1024px App 圖示原稿、Android Feature Graphic、Android/iOS 各尺寸實際遊戲截圖、隱私政策公開網址、支援網站及客服信箱。

**不可寫入宣傳**：尚未通過實機測試的環境光、圖示切換、所有裝置的截圖錄影偵測、所有手機皆可使用的感測功能。
