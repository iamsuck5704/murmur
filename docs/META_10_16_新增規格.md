# Meta Horror #10 擴充與 #16 新增規格（待原生實作）

## #10 截圖 + 螢幕錄影
- 截圖：在原生系統提供事件時顯示既定劇情台詞。
- 螢幕錄影：偵測系統可提供的擷取狀態變化，在錄影啟動時顯示一次「你想把這些都留下來嗎。」；避免每幀重複觸發。
- 不讀取截圖或影片內容、不阻止使用者擷取、不偽裝成系統警示。
- iOS：以系統的螢幕擷取狀態／變更事件實作，須測試錄影、鏡像投放、AirPlay 等不同來源，避免錯判。
- Android：依支援的 OS API 實作；不支援的版本不假裝偵測成功，顯示功能不可用或採劇情替代。
- 實況模式可關閉個人化台詞；減少動態效果時只顯示靜態提示。

## #16 連續環境聲音
- 在設定中由玩家主動啟用；清楚說明要使用麥克風、目的及何時停止。
- 只計算本機音訊音量強度（例如短時間 RMS 與持續時長），不做語音辨識、不轉文字、不存檔、不上傳、不保留音訊緩衝作為紀錄。
- 只有 App 前景、加害者篇特定場景，才允許啟動。退出場景、切背景、停用或拒絕權限立即關閉音訊串流。
- 持續高於環境基線約 8～12 秒後，最多觸發一次：「你在跟誰說話？」「……你是在跟別人分享嗎？」；須有冷卻時間避免騷擾。
- 聲音強度不等於人聲或對話，可能來自電視、音樂、車流、風扇；台詞採疑問句，不宣稱知道玩家在做什麼。
- 需更新 iOS 麥克風用途說明、Android 權限、商店資料安全表單與隱私政策。
- 未授權時不影響通關；未提供真實感測資料時，不以虛構結果冒充實測。

## 本包狀態
這是原生功能需求與隱私約束文件，**尚未接入 iOS/Android 原生偵測或麥克風**。本包仍是 WebView 核心與 HTML 預覽，沒有可安裝的 APK/IPA。
