# Murmur 已定案事項、待辦與交付檢查

更新：2026-10-10；本檔記錄本輪工作，不取代交接包正式企劃。

## 已定案

- 網頁版提供第一、第二周目；原生 App 包含第一、第二周目及加害者篇。
- **第一周目結束即可解鎖加害者篇**。網頁版第一周目後提供索引碼；第二周目後顯示 App 下載位置。沒有索引碼的 App 玩家完成第一周目即可進入加害者篇。
- 加害者篇：閱讀手機備份，不是與 7f3 即時聊天；E1、E2、E3、童年插章、E4、E5、尾聲。
- v0.5 原文禁止自行改寫、增寫、潤飾或刪減；先用佔位介面讓作者手機測試。
- 交接包第 5、6 節優先；不描述性暴力過程、自傷方法，不使用 A 的跨性別身分勒索。
- 2021-04-10 23:51 前後的「她／他」稱呼規則必須遵守，後段「他→你」變化保留。
- 2021-02-20 歌曲群發、2021-04-15 劃掉「你是我的」、三處不含方法的自傷文字、稱呼轉換、虛構歌曲〈雨停之前〉及歌詞：**全部保留**。
- 不讀通訊錄、照片庫、麥克風、剪貼簿；定位最多到「區」；不引導玩家拿手機撞頭。
- 紅色視覺效果不得快速閃爍，一次轉紅後在 0.5～1 秒淡出，遵守 reduced motion。通知一定要清楚標示 Murmur，不偽裝真人或系統通知。
- 驚嚇效果開關／實況模式／拒絕授權可繼續遊玩，必須在正式功能上線時逐項實現。
