# Murmur v0.6.1：括號／開發註記稽核

稽核來源：交接包「加害者篇文字草稿 v0.5」與 v0.6 程式的 `renderMarkup`。原始 `ARCHIVE` 正文與章節文字不變，只更動呈現層。

## v0.6 原本已處理
- 「這一頁其他地方是空白的」「只有日期」：空白版面。
- 「這一行被劃掉」「下面一行，被劃掉」「下面一行，被劃掉，看得出來」「『妳』被劃掉」：刪除線；真正的文字保留。
- 「下面寫了十四次同一句」：14 行重複、字體縮小。
- 「下一頁，同一天」「隔天」「同一頁，最下面」「再下面」「同一頁，最下面，字很工整」：分頁、留白與字距。
- 「刪除」「空白」時間列：記錄狀態。
- 4/10「她說」轉「他說」：既有動畫。

## v0.6.1 修正
- 「再下面一行，字比較小」：不再顯示指示，改為頁尾間距 + 下一行縮小。
- 「以下紀錄已由檢方扣押」：不再把原始括號說明顯示給玩家，改為獨立的封存狀態框。
- 檔案標題中的開發註記改成 UI 名稱與 metadata，例如「最後一篇（現有排序題保留）」只顯示「最後一篇」，yoru 附註顯示「E-ROOT」作為標籤。
- 04-10 v1/v2 副本在 UI 顯示為明確的版本標記，而非原稿括號說明。
- 回覆紀錄 Markdown 表格改為真正可橫向捲動的表格；上線紀錄的 Markdown code fence 改為 `<pre>`。
- 回覆紀錄／上線紀錄的「最下面一行」排版指示改為留白後的實際文字，不再印出開發說明。

## 不應刪除的括號
- A 的訊息「好喔（」「不要跟咱說加油啦（」等未閉合括號是角色語氣。
- 7f3 備忘錄裡「布丁（便利商店的……）」「生日：還不知道（不要直接問……）」等是她的原始文字。
- 「（空白）」「（刪除）」在原稿中是資料狀態指示，不當作普通句子。
