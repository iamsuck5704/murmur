# Murmur CMD v0.4：終端機目錄 + 手機觸控優先

依照手機截圖意見，移除主頁原本的雙欄小 App 卡片，改為真正的 CMD `DIR` 單欄文字目錄。所有項目仍是點擊式按鈕，不必輸入文字。保留 11 個資料夾、七章進度與儲存、既有網頁主線及索引碼流程。

## 手機 RWD 重點

- 目錄列最少 74 CSS px，高度可隨中文字與系統字級增加；鎖定項同樣保留列高。
- 章節列至少 70 px、檔案列至少 76 px、任務列至少 64 px；頂部返回／設定按鈕至少 52 px。
- 縮窄到 320px 時不會縮小文字與點擊區，優先讓名稱換行。
- 手機安全區域、橫向短畫面、長檔名、系統「減少動態效果」均考慮在內。
- 保留 `:focus-visible` 鍵盤焦點、狀態文字與點擊提示，避免僅靠綠／黃顏色分辨。
- CSS / JS 與單檔 `preview-standalone.html` 同步，仍只有佔位文字，沒有新增網路連線或原生權限。
