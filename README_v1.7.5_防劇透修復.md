# Murmur v1.7.5｜玩家介面防劇透修復

此版由 v1.7.4 修改，不清除存檔，不改動核心劇情與解謎答案。

- [SET] 不再預先顯示鏡子、E5 行政區、通關後第三天通知等觸發時機。
- 進階權限選項與裝置診斷收進需主動展開的區塊，仍保留每項權限的資料用途、撤回方式與測試入口。
- 首次入場僅啟用玩家明確選擇的相機、麥克風、定位、通知；不再順便開啟截圖／錄影、動作或環境光效果。後三項需另行同意。
- 相機、定位、天氣與通知的權限說明不透露故事章節、特定日記或演出時間。
- 修正 E3 章節提示、謎題標題與早期劇情結論外洩。
- 清理音訊／刪除／統計／行事曆占位文件中暴露開發狀態的文字；首頁不再出現 Meta 測試狀態。
- 法律文件保留資料類型、用途、第三方與拒絕／撤回資訊，刪除不必要的章節與觸發時間細節。
- 不會隱瞞系統級權限用途；使用者若主動展開權限管理或閱讀隱私政策，仍可了解功能與風險。

## Windows 更新

先備份 D:\murmur，再將覆蓋包檔案解壓到 D:\murmur，執行：

```powershell
cd D:\murmur
npm run test:permissions
npm run test:spoilers
npm run build:web
npx cap sync android
python scripts/patch_android.py
npx cap open android
```

重新在 Android Studio 建置、安裝測試。原生相機／麥克風／定位授權失敗屬另一項待實機驗證問題，本版主要處理防劇透。
